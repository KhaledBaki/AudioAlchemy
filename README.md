# AudioAlchemy

AudioAlchemy is an interactive music creation web application built for a software engineering project. It gives users multiple ways to explore music through creative tools such as Freeform performance, Backtracking, AI-assisted idea generation, a metronome, and an editor.[1]

## About the Project

The goal of AudioAlchemy is to make music creation feel more interactive, approachable, and creative. Instead of focusing on only one way to build music, the project combines several tools that support experimentation, structure, and inspiration in one themed application.[1][2]

Users can experiment with live input, explore guided composition features, and use AI-assisted tools to generate musical ideas. The app was designed to be both functional and visually engaging, with multiple themed interfaces and simple navigation between sections.[3]

## Features

- Freeform music interaction
- Backtracking and guided music building
- AI-assisted music idea generation
- Metronome and music editor tools
- Theme-based interface design[2][4]
